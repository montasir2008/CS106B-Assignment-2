Q2. For which type of inputs does the function go into an infinite loop?
A2. The function enters an infinite loop when the queue is nonempty and contains only negative numbers, because the queue size increases with every iteration, preventing the loop from terminating.

Q3. Show your edited code for `duplicateNegatives` that fixes the problem with the infinite loop.
A3.
void duplicateNegatives(Queue<int>& q) {
    int length = q.size();
    for (int i = 0; i < length; i++) {
        int val = q.dequeue();
        q.enqueue(val);
        if (val < 0) {
            q.enqueue(val);   // double up on negative numbers
        }
    }
}
